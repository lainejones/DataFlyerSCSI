# DataFlyerSCSI manual

The manual for `dataflyer.device`, a driver for the Expansion Systems DataFlyer
1200 SCSI+ on AmigaOS 3.1 and newer. These pages are also the `DataFlyerSCSI.guide`
in the package.

1. [Introduction](01-introduction.md): what it is, what you get, what you need.
2. [Installing](02-installing.md): the installer, by hand, the boot lines, a CD-ROM,
   updating and removing.
3. [How it works](03-how-it-works.md): the card, the driver, units.
4. [Tools](04-tools.md): RDBMount, flytest, flystat, flychange and the rest.
5. [Partitions](05-partitions.md): HDToolBox and speed.
6. [Troubleshooting](06-troubleshooting.md)
7. [About](07-about.md): licence, source, credits.
